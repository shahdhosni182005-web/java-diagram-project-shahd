## Description
A Java OOP project implementing a UML class diagram: an abstract `Employee` class with
three subclasses (`CommissionEmployee`, `MonthlyEmployee`, `HourlyEmployee`), a `Department`
that manages a list of employees and calculates payroll, and a `Gender` enum.

## How to run
```bash
javac -d out $(find src -name "*.java")
java -cp out Main
```
Or open the folder in IntelliJ/Eclipse/VS Code and run `Main.java` (or `test/MainTest.java`).
